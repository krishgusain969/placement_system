# Placement Management System

A full-stack placement management portal built with FastAPI, MySQL, React, and an OS Lab simulation module.

## Project Structure
- `database/`: Database schema, tables (3NF), stored procedures, triggers, views, and seed data.
- `docs/`: System documentation, ER diagrams, and API specifications.
- `backend/`: FastAPI backend service with JWT authentication and business logic.
- `frontend/`: React + Vite + Tailwind CSS dashboard.
- `os_lab/`: C source code demonstrating CPU scheduling, semaphores, and deadlock detection.
